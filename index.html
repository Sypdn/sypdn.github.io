Sistem Keamanan Kendaraan Berbasis ESP32

Sistem pemantauan kendaraan dengan deteksi getaran, kontrol relay, pelacakan GPS, dan dashboard web untuk melihat status perangkat.

  • Deteksi getaran dengan respons alarm pada perangkat.
  • Pemantauan lokasi GPS dan status melalui dashboard.
  • Kontrol relay dari dashboard maupun remote RF.
